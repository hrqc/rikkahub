# M2.19：本地搜索与购物比较修复（210 内部版）

## 本轮目标与实际边界

V1 的验收目标是自主搜索、翻页、比较同需求商品、核对评价与可用优惠，给出有证据的选择，并可准备购物车和结算。最终下单、支付仍须用户确认。当前还未完成这条业务链，不能用单元测试或宿主手动操作代替实机验收。

209 的两次搜索点击在控制器快照门禁被拒绝，尚未进入后端重新检查；详见 `M2_18_SEARCH_ENTRY.md`。210 解决方案包含：

- 京东 `phone_*_search(query)`：本地组合至多三个原有受控动作，逐步获取新观察、打开搜索、输入并核对查询词、提交。每步继续检查授权、前台、快照、预算及暂停；未知结果不重放。提交不代表商品筛选完成。
- 为点击门禁增加固定枚举诊断，区分未建立证据、证据不合格、锚点清除和身份变化。诊断不输出额外页面正文、完整原生树或内部指纹。
- 保留原同款比较，新增功能替代品模式。首个已实现类别为 USB-C 数据线，依据完整引用节点中的接口、功率、长度及每包条数分组，允许不同品牌比较。未知、多规格、范围、约数和不清楚的计价单位进入待核实列表。
- 多条装须有与金额直接对应的整包价格，单条价格不能作为包价；待核实候选只保留原始事实，不输出派生确认实付。
- 新增显式启用的 Android 搜索验收，使用生产搜索流程；其输出仅包含状态、动作执行器和门禁诊断，不输出查询词或购物正文。
